# 行业笔记 / Industry Notes

个人投资者向的行业研究 H5：大厅 → 书 → 章。图表优先，中英 URL 分语言。

## 开发约定：多语言

**开发期只做中文（`zh`）和英文（`en`）。**  
日 / 法 / 德 / 西 / 韩 / 阿等重要语言，等功能与内容都稳定后再批量适配。

这样可以避免：

- 每加一章就改 8 套文案
- UI、路由、RTL 在需求还在变时反复返工
- 半成品文案污染已发布内容

### 当前启用

| 代码 | 语言 | 状态 |
| --- | --- | --- |
| `zh` | 中文 | 开发与内容主语言 |
| `en` | English | 与中文同步维护 |

语言切换目前是顶栏双按钮（中文 / English）。

目标 UI：单一语言按钮 + **下拉菜单**切换（见 `lib/locales.ts` 计划清单）。

### 适配时的顺序（不要提前做）

1. 功能与章节内容在 **zh / en** 定稿  
2. 把 `ACTIVE_LOCALES` 扩到计划列表；语言切换改成下拉  
3. 补 `lib/ui.ts` 壳文案（导航、按钮、免责声明）  
4. 正文：非中文可读英文回退，再按语言补全书翻译  
5. 阿拉伯语单独验收 RTL 与版式  

清单与元数据（本地名、方向、Accept-Language）集中在 [`lib/locales.ts`](./lib/locales.ts)，**不要在业务代码里散落语言码**。
